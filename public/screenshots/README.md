# Screenshots

Place your app screenshots here to populate the homepage.

## Required files (PNG or WebP)

| Filename | Used in |
|---|---|
| `dashboard.png` | Hero section + Screenshots section |
| `today.png` | Screenshots section |
| `grid.png` | Screenshots section |

## How to take screenshots

1. Run the app locally: `npm run dev`
2. Go to each page and take a screenshot at ~1280×800px
3. Drop the files in this `/public/screenshots/` folder — no code changes needed

The homepage image paths are all set to `/screenshots/dashboard.png`, `/screenshots/today.png`, and `/screenshots/grid.png`. Just drop the files in and they'll appear automatically.

## Placeholder behavior

Until real screenshots are added, the homepage shows styled placeholder boxes with descriptive labels. The layout is identical — only the images change.
